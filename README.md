# Models

3Dプリント向けのパラメトリックモデルを生成するブラウザアプリ。

モデルごとの仕様:

- [3-Key Switch Tester](docs/specs/switch-tester.md)
- [Instrument Stand](docs/specs/instrument-stand.md)
- [VideoMic Me-C Stand](docs/specs/videomic-me-c-stand.md)
- [Cherry Keycap](docs/specs/cherry-keycap.md)

開発:

```sh
pnpm install
pnpm dev
```

```sh
pnpm test
pnpm build
```
