# 3-Key Switch Tester

横一列の3穴、底なし・基板なしの枠を生成する。

## 既定寸法と調整

- 外形: 62×24×12mm
- ピッチ: 19.05mm
- 穴幅: 14.1mm
- 天板厚: 1.5mm
- 側壁厚: 2mm

穴幅・全高・側壁厚を調整でき、STL/3MFは天板を下にした印刷向きで出力する。

## 寸法の根拠と嵌合確認

穴と天板厚の基準は[CHERRY MX寸法図](https://www.smcelectronics.com/DOWNLOADS/CHERRYMX.PDF)の14mm角・1.5mm厚。既定穴には幅全体で+0.1mmの印刷補正を追加している。ユーザーの実物確認でスイッチがぴったり嵌合。
