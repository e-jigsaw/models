# Cherry Keycap

R1〜R4、MX互換ステム、2色の角丸菱形インレイを生成する。

## ステムの形状と既定寸法

- 角形ステム: 角丸5.37mm四方
- 嵌合補正: 0.1mm
- 十字穴: 4.10×1.40 / 1.30×4.025mm
- 差し込み深さ: 4mm

根元だけにT字リブを配置。丸形も選択可能。

角形ステムの寸法参考は[Keycap Playground / stems.scad](https://github.com/riskable/keycap_playground/blob/master/stems.scad)。コード転載ではなくJSCADで独自構築している。

## 印刷と嵌合確認

0.2mmノズル向け。補正0.2mmでは緩く、0.1mmの試験軸はユーザーの実物確認でぴったり嵌合。実スイッチの嵌合はテスト印刷で確認する。
